# Tokina DM Support

Un membre envoie un DM au bot, choisit une raison, puis échange avec le staff depuis un ticket privé.

Commandes : /dmsupport setup, /dmsupport statut et /dmsupport fermer.

Active Message Content Intent. Le bot doit pouvoir gérer et voir les salons, envoyer des messages, intégrer des liens et joindre des fichiers.
